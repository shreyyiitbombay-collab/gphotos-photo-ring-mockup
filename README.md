# Google Photos — Photo Ring Mockup

An interactive, self-contained HTML mockup prepared for embedding in a Behance project as a live prototype.

## Run locally
Download `index.html` and open it in a modern desktop browser. The images and interaction code are embedded in the file, so no build step or external dependencies are required.

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. Once GitHub Pages finishes publishing, your demo URL will be:
   https://shreyyiitbombay-collab.github.io/gphotos-photo-ring-mockup/

## Add to Behance
In your Behance project, add a **Link / Embed** block and paste the live GitHub Pages URL. If Behance doesn't render it inline, use a clear **View Interactive Prototype** link.

Note: GitHub Pages must be enabled after the site files are added.
